# オートクリッカー (Android)

画面上の指定した1点を、一定間隔で自動タップし続けるシンプルなAndroidアプリです。
アクセシビリティサービスの `dispatchGesture` を使ってタップを再現します。

## 使い方(アプリ側)
1. アプリを起動し「1. アクセシビリティ設定を開く」をタップ
2. 設定内の一覧から「オートクリッカー」を探してONにする
   (「この機能を使用しますか」的な確認が出るので許可する)
3. ONにすると画面に **赤い丸(タップ位置)** と **操作パネル** が浮かんで表示される
4. 赤い丸をドラッグしてタップしたい場所へ移動
5. 操作パネルの「間隔: ... (タップで変更)」をタップして間隔を変更
   (100 / 300 / 500 / 1000 / 2000 / 5000 ms を順に切り替え)
6. 「開始」を押すと自動タップが始まる。もう一度押すと停止
7. 「終了」でオーバーレイを消してサービスを無効化

## ビルド方法(お手元での作業)
この一式はソースコードのみです。実行可能な .apk にするには、ご自身の環境で
Android Studio を使ってビルドしてください。手順:

1. [Android Studio](https://developer.android.com/studio) をインストール
2. `AutoClicker` フォルダを Android Studio で開く (Open an existing project)
3. Gradle の同期が自動で始まるので待つ (初回はネット接続が必要)
4. 実機を USB接続 (開発者向けオプション → USBデバッグ をON) するか、
   エミュレータを起動
5. 上部メニューの ▶ (Run) を押すとインストール&起動される
6. apkファイル単体が欲しい場合は
   `Build > Build Bundle(s) / APK(s) > Build APK(s)` を選択
   → `app/build/outputs/apk/debug/app-debug.apk` が生成される

## 注意点
- アクセシビリティサービスの権限は強力なため、野良apk配布時にストアの審査は通りません。
  自分の端末で使う分には問題ありません。
- ゲームなど一部アプリの利用規約でオートクリッカーの使用を禁止している場合があります。
  規約違反によるアカウント停止等は自己責任となりますのでご注意ください。
- `minSdk 24` (Android 7.0以上) を対象にしています。
